## 📖 File Descriptions

### Script Files

#### 1. google-apps-script.js
**Fungsi:** Script utama untuk sinkronisasi data antara GitHub dan Google Spreadsheet

**Fitur:**
- ✅ Sync dari GitHub ke Spreadsheet
- ✅ Sync dari Spreadsheet ke GitHub (dengan token)
- ✅ Auto sync dengan trigger
- ✅ Setup otomatis
- ✅ Logging aktivitas
- ✅ Menu custom di spreadsheet

**Cara Pakai:**
1. Copy isi file ke Apps Script editor
2. Edit CONFIG (username, repo, path)
3. Jalankan setup()
4. Jalankan syncFromGitHub()

#### 2. validator.js
**Fungsi:** Script untuk validasi struktur data export.json

**Fitur:**
- ✅ Validasi struktur JSON
- ✅ Cek error dan warning
- ✅ Tampilkan summary data
- ✅ Integrasi dengan spreadsheet

**Cara Pakai:**
1. Upload ke Apps Script editor
2. Jalankan validateExportFile()
3. Lihat hasil di sheet "Validation"
